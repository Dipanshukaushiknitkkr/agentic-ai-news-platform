# OpenAI’s new voice mode makes it to the ChatGPT desktop app

**Published:** Fri, 24 Jul 2026 13:36:42 +0000

**Link:** [https://techcrunch.com/2026/07/24/openais-new-voice-mode-makes-it-to-the-chatgpt-desktop-app/](https://techcrunch.com/2026/07/24/openais-new-voice-mode-makes-it-to-the-chatgpt-desktop-app/)

**LLM Summary:** OpenAI has rolled out a new voice mode in the ChatGPT desktop app, allowing users to control the app with voice commands. This feature integrates with both ChatGPT Work and Codex, enabling more efficient task completion and agent control. Users can now interact with the app in a more hands-free and intuitive way, using voice to guide their conversations.

ChatGPT Voice on desktop can work with both ChatGPT Work and Codex to complete tasks and control agents.
